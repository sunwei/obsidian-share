# Welcome — MDFriday Share smoke vault

This vault is for **real** Obsidian testing of the MDFriday Share plugin against **staging** (`api.fsky.top` / `share.fsky.top`).

## Quick smoke

1. Open this folder as a vault in Obsidian.
2. Enable **MDFriday Share** (Community plugins) if needed — `community-plugins.json` already lists it.
3. Open [[Notes/sample-share-note]].
4. Right-click the note → share / use the Share ribbon (`dice-1`).
5. Expect a public URL like `https://share.fsky.top/s/…` and ~**7 days** remaining (Guest).

See `README.md` in this folder for rebuild / reload steps.
